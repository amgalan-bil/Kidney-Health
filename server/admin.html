The key is set on the server as ADMIN_KEY. It stays in this browser tab only and is cleared when you close it.

Gifts

"General fund" lists paid gifts that aren't credited to any student. Where a gift's message names a student, that student is pre-selected and marked Suggested; it is only a guess until you press Move. Check with the family if you're not sure.

Record an offline gift

For money collected outside the site: cash, bake sales, bank transfers. It counts toward the student's total and shows on their page. Only record money that has actually reached the campaign account.

Donorbox student list

In Donorbox, add a required dropdown question whose wording includes the word "student", e.g. "Which student are you supporting? / Аль сурагчийг дэмжих вэ?". Paste these lines as its options. Each student's code (HB-…) never changes, so renaming a student won't break anything. When new students join, copy the list again.

Totals check

Compares each student's total on the site with the sum of their paid gifts. A difference can mean cash someone added by hand, so ask before fixing.
